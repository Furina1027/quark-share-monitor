# 教育部《全国硕士研究生招生工作管理规定》发布监控

盯住教育部官网，**《2027 年全国硕士研究生招生工作管理规定》一发出来就发邮件通知**。

---

## 快速开始

```bash
pip install -r requirements.txt

python 教育部.py --test-mail      # 先确认邮箱通道能用
python 教育部.py --once --dry-run # 跑一轮，只看抓取结果，不发邮件
python 教育部.py                  # 正式常驻运行
```

常驻运行时每 1 小时检查一次，命中就发邮件，日志写在 `logs/monitor.log`。

### 命令行参数

| 参数 | 作用 |
|---|---|
| （无） | 常驻运行，按 `config.CHECK_INTERVAL` 循环 |
| `--once` | 只检查一轮就退出，适合放进系统计划任务 |
| `--dry-run` | 检查但不发邮件，用来验证抓取是否正常 |
| `--interval 600` | 临时把检查间隔改成 600 秒 |
| `--test-mail` | 只发一封测试邮件 |

```bash
python selftest.py   # 40 项自测，确认匹配逻辑与抓取链路正常
```

## 监控原理

不猜页面结构，也不再用绝对 XPath。脚本把「**官方文件列表**」整页抓下来，
按 **URL 模式**（`/t20260916_1450989.html`）取出所有条目，再对标题做
**归一化后的关键词匹配**：

- **文件本体**（`FILE`）：标题同时含 `2027` 和 `全国硕士研究生招生工作管理规定`
- **相关信号**（`SIGNAL`）：标题含 `2027` + `全国硕士研究生` + `招生`
  （教育部通常先发一条「教育部部署 2027 年全国硕士研究生考试招生工作」的新闻，
  这条新闻会直接链向规定正文，可以作为提前量）

### 数据源

| 源 | 地址 | 说明 |
|---|---|---|
| 教育部文件 | `www.moe.gov.cn/was5/web/search?channelid=239993` | 官方文件列表，按发布顺序倒排，新文件出现在顶部 |
| 教育部新闻通稿 | `www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/` | 每年的「部署…考试招生工作」新闻都在这 |

命中文件本体后，脚本会跟进正文页，抽取 **发文字号 / 生成日期 / 信息索引 / 全文**，
存到 `data/documents/`，并把要点写进通知邮件。

## 相比 2025 年那版改了什么

| 问题 | 旧版 | 现在 |
|---|---|---|
| 定位方式 | 绝对 XPath `/html/body/div[6]/div[4]/div[8]/div[2]/ul`，页面一改版就永久失效 | 按 URL 模式 + 关键词匹配，不依赖 DOM 层级 |
| 匹配方式 | `标题 == 关键词` 全等比较，尾随空格/全角数字就匹配不上 | NFKC 归一化 + 关键词包含，全角数字、空格、书名号变化都能匹配 |
| 抓取方式 | 每轮启动一次 Chrome + chromedriver，约 3–8 秒 | 纯 `requests`，一轮约 0.5 秒；**已不需要 chromedriver** |
| 失败处理 | 异常被吞掉，只打印一行「解析失败」，然后静默等下一小时 | 重试 + 退避；**抓到页面却解析不出条目 = 上报为错误**，不再和「没有新文件」混为一谈 |
| 告警 | 无。跑挂了没人知道 | 连续 3 轮全部源失败就发告警邮件 |
| 日志 | 只有控制台输出，关掉就没了 | 控制台 + 轮转文件 `logs/monitor.log` |
| 重复通知 | 无去重，重启就会再发一遍 | `state.json` 记录已通知链接，同一文件只发一次 |
| 数据 | CSV 36 行里 12 行完全重复，date 字段两种格式混用 | 去重到 20 行，年份/类型/发布日期拆成独立字段 → `data/notices.csv` |
| 可配置性 | 关键词、邮箱、间隔散落在代码各处 | 全部集中在 `config.py` |

## 部署成长驻任务（可选）

如果不想开着一个黑窗口，可以用 Windows 计划任务，每 30 分钟跑一次：

```powershell
$py  = "C:\Users\huang\AppData\Local\Programs\Python\Python311\python.exe"
$arg = "E:\python\爬网站\教育部\教育部.py --once"
schtasks /create /tn "教育部招生规定监控" /tr "`"$py`" `"$arg`"" /sc minute /mo 30 /f
```

`--once` 模式天然适合计划任务：跑完就退出，不会留下常驻进程。

## 已知边界

- `was5` 列表是「最新 15 条」，**依赖轮询频率**。按 1 小时一次，不可能错过。
  如果改成几天跑一次，建议同时看新闻通稿源（那个列表更长）。
- 命中判定依赖标题里出现年份数字。历年标题格式稳定，但如果教育部换了表述方式，
  只需在 `config.py` 调整 `CORE_KEYWORD` / `SIGNAL_KEYWORDS`。
